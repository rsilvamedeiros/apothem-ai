# Public API and SDK Roadmap

**Status:** Foundation / Draft  
**Project:** APOTHEM AI  
**Canonical domain:** `apothemai.com.br`

### MVP
Private/stable API used by APOTHEM web and selected design partners.

### Post-MVP
Formal public API docs, API keys/service accounts, webhooks, usage quotas and TypeScript SDK.

### Later
Python SDK, embedded/white-label agent surfaces, connector SDK and marketplace APIs.

Public API launch requires stronger compatibility/deprecation guarantees than internal routes, so do not expose implementation-shaped endpoints prematurely.
