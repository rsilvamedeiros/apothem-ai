# Interaction Patterns and Visual Language

**Status:** Foundation / Draft  
**Project:** APOTHEM AI  
**Canonical domain:** `apothemai.com.br`

Important patterns:
- progressive disclosure of technical details;
- explicit draft vs published state;
- irreversible/high-risk actions visually differentiated;
- async processing with observable status rather than frozen screens;
- evidence/source previews near generated claims;
- approval decisions separated from conversational text;
- execution timeline as a standard pattern across agents and workflows.

Motion should clarify transitions/processing and respect reduced-motion settings. Avoid decorative “AI thinking” animations that imply certainty or expose fictional reasoning.
