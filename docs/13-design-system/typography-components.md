# Typography and Components

**Status:** Foundation / Draft  
**Project:** APOTHEM AI  
**Canonical domain:** `apothemai.com.br`

Typography favors legibility and hierarchy over “futuristic” styling. Product density should support enterprise data without feeling like a developer console everywhere.

Core components expected early:
Button, Input, Select, Combobox, Dialog, Drawer, Tabs, Tooltip, Menu, Table/DataGrid pattern, Status Badge, Empty State, Skeleton, Toast, Callout, Code/JSON viewer, Timeline, Citation, Approval Card, Tool Call Card, Run Status, File/Source item.

Business feature components remain in their features; primitives/patterns enter the shared UI package after reuse is demonstrated.
