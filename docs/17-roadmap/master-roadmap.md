# Master Roadmap

**Status:** Foundation / Draft  
**Project:** APOTHEM AI  
**Canonical domain:** `apothemai.com.br`

## Phase 0 — Foundation (now)
Documentation, architecture, repository scaffold, local development, CI, identity/tenancy skeleton.

## Phase 1 — Core Agents
Organizations/workspaces, agent drafts/versions, model gateway, runs, streaming/status, execution history.

## Phase 2 — Knowledge
Uploads, ingestion, parsing/chunking, embeddings/hybrid retrieval, citations, knowledge permissions.

## Phase 3 — Connect + Actions
Connections, first connector/tools, policy engine, approval flow, idempotent tool execution.

## Phase 4 — Flow
Durable workflow versions/executions, triggers, conditions, agent/tool/approval nodes.

## Phase 5 — Control / Enterprise
Advanced audit, SSO/SCIM, retention controls, evaluation dashboards, budgets, enterprise policies.

## Phase 6 — Ecosystem
Public API/SDK, connector SDK, templates/marketplace, white-label/embedded capabilities.
