# Architecture Decision Records

**Status:** Foundation / Draft  
**Project:** APOTHEM AI  
**Canonical domain:** `apothemai.com.br`

ADRs record decisions that materially constrain future implementation. Accepted ADRs outrank earlier exploratory documentation.

Format: Context → Decision → Consequences → Alternatives → Status.

Do not create an ADR for trivial library choices; use it for architecture/security/domain decisions that a future engineer might reasonably try to reverse.
