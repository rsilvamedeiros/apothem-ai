# Personas

**Status:** Foundation / Draft  
**Project:** APOTHEM AI  
**Canonical domain:** `apothemai.com.br`

## Organization Owner — “I need control and business value”

Needs confidence that AI adoption does not create unmanaged access. Cares about ROI, governance, vendor risk, cost and adoption. Does not want provider/model details dominating setup.

## Builder / Automation Lead — “I need to configure behavior without rewriting the platform”

Understands processes and sometimes code. Needs agent versioning, knowledge/tool configuration, test environments, clear errors, evals and safe publishing.

## Business Operator — “I need the work completed, not an AI demonstration”

Interacts with agents in everyday tasks. Needs concise outcomes, evidence, clear next steps and transparent approval requests. Should not need to understand RAG or tool schemas.

## Security / Auditor — “Show me exactly what happened”

Needs identity, resource, policy, tool, approval, data access and execution history. Requires filters/export later, immutable audit semantics and confidence that application logs are not the only evidence.

## Developer / API Integrator — “Give me stable contracts”

Needs scoped API credentials, idempotency, typed errors, webhooks/events, SDK-quality documentation and predictable versioning.
