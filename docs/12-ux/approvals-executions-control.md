# Approvals, Executions and Control UX

**Status:** Foundation / Draft  
**Project:** APOTHEM AI  
**Canonical domain:** `apothemai.com.br`

Approval card must answer before a decision:
- What will happen?
- Which resource/customer/system is affected?
- Which agent/run requested it?
- Why is approval needed?
- What exact fields/amount/destination will be used?
- What is the deadline/expiration?

Runs/Activity should provide timeline of state transitions, evidence, tool actions, approval, usage and classified errors with role-appropriate detail.

Control views later aggregate success/failure, approval rates, policy denials, cost, latency and eval health by workspace/agent/model/tool.
