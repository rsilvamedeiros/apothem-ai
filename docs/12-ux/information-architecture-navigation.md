# Information Architecture and Navigation

**Status:** Foundation / Draft  
**Project:** APOTHEM AI  
**Canonical domain:** `apothemai.com.br`

Primary navigation should communicate the operating model rather than AI jargon:

- **Overview**
- **Agents**
- **Knowledge**
- **Connections**
- **Flows** (when enabled)
- **Approvals**
- **Runs / Activity**
- **Settings**

An organization/workspace switcher stays globally available. Control/governance surfaces can become role-dependent rather than creating a separate confusing “admin product” initially.

The interface should progressively reveal technical detail: operators see outcome/status; builders can inspect tool/model/evidence details; auditors can inspect immutable records.
