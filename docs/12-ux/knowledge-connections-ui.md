# Knowledge and Connections UX

**Status:** Foundation / Draft  
**Project:** APOTHEM AI  
**Canonical domain:** `apothemai.com.br`

Knowledge UI needs source health and provenance: source name/type, processing/sync status, last updated, item count, access scope, error details and reprocess/re-sync controls.

Connections UI should show system/account identity, granted scopes, status, last successful use/sync, tools made available and safe reconnect/revoke actions. Secret values are never displayed after storage.

When attaching a connection/tool to an agent, show the actual capability (“Read customers”, “Update opportunity”) rather than only connector brand.
