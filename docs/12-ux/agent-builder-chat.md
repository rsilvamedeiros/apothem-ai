# Agent Builder and Chat UX

**Status:** Foundation / Draft  
**Project:** APOTHEM AI  
**Canonical domain:** `apothemai.com.br`

## Builder sections
- Overview: name, purpose, owner/status.
- Instructions: outcome-focused behavior and constraints.
- Knowledge: attached bases with access summary.
- Tools: bindings, scopes, risk/approval mode.
- Model: policy/tier, not provider complexity by default.
- Memory: what is retained and why.
- Tests/Evals: scenarios and results.
- Versions: draft/published history and rollback.

## Chat/task surface
Messages should render citations, structured outputs, proposed actions, approval status and tool progress as first-class UI. Do not display hidden chain-of-thought. Provide concise execution explanation/timeline instead.
