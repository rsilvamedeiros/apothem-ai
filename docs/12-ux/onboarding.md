# Onboarding

**Status:** Foundation / Draft  
**Project:** APOTHEM AI  
**Canonical domain:** `apothemai.com.br`

Goal: reach a useful, safe first run quickly without pretending integrations/permissions do not matter.

Suggested onboarding:
1. organization/workspace identity;
2. choose a use-case template or blank agent;
3. define job/outcome;
4. add knowledge;
5. add connection/tool only if needed;
6. choose autonomy default (safe recommendation/approval first);
7. run a guided test;
8. publish.

Show progress and explain why a permission is requested. Avoid forcing pricing/advanced governance setup before first value for design partners.
