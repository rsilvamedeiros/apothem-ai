# Go-to-Market Direction

**Status:** Foundation / Draft  
**Project:** APOTHEM AI  
**Canonical domain:** `apothemai.com.br`

Initial message should sell outcomes and operational integration, not “autonomous agents” as an abstract category.

Entry motion:
1. identify a real repetitive/knowledge-heavy business process;
2. quantify current pain/risk/time;
3. deliver solution using APOTHEM Core primitives;
4. measure outcome;
5. generalize reusable connector/tool/template/eval into platform.

Ideal early use cases have clear data sources, limited action surface, measurable value and a human approval point for meaningful risk.

Avoid projects that are mostly unrelated custom CRUD systems; they consume capacity without improving the intelligence core.
